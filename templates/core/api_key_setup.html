Setup Instructions

1

Get API Keys from Pionex

  1. Log in to your Pionex account
  2. Go to Settings → API Management
  3. Click Create API Key
  4. Set permissions: Enable Read and Trade
  5. Complete 2FA verification
  6. Copy your API Key and Secret Key
Important: Never share your API secret. Store it securely.
2

Configure Environment Variables

API keys should be set as environment variables for security. Choose one method:

Option A: Docker Compose (Recommended)

Add to your .env file in the project root:

PIONEX_API_KEY=your_api_key_here
PIONEX_API_SECRET=your_api_secret_here

Option B: Portainer

In Portainer Stack configuration, add environment variables:

environment:
  - PIONEX_API_KEY=your_api_key_here
  - PIONEX_API_SECRET=your_api_secret_here

Option C: Shell Export

For local development:

export PIONEX_API_KEY="your_api_key_here"
export PIONEX_API_SECRET="your_api_secret_here"
3

Restart Services

After setting environment variables, restart the application:

docker-compose restart

Or in Portainer, redeploy the stack.

4

Verify Connection

Return to this page to verify the API keys are configured. The status should show green checkmarks.

You can also test the connection by viewing your portfolio on the dashboard.

Security Best Practices

  • Never commit API keys to version control. Use .env files that are gitignored.
  • Use IP whitelisting on Pionex if possible to restrict API access.
  • Enable withdrawal whitelist on Pionex to prevent unauthorized withdrawals.
  • Regularly rotate API keys and revoke unused ones.
  • Monitor API usage on Pionex for suspicious activity.
  • Start with dry-run mode to test the system before enabling live trading.
